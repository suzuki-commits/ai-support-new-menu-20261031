STRATEGY MEMO ｜ 2026-10-31

「学んだら自分でやる」時代の
AI支援は、何を売るべきか

企業304社・経営者88人にAI活用支援を提供するA社の、継続課題の分析と新メニュー案

根拠の種類を色で区別しています：公的統計調査（一次確認済）A社の社内記録二次情報仮説

結論

  1. 「継続しない」には2種類あります。自走できるようになって離れる「卒業型」と、自走の手前で止まって消える「失速型」です。A社の記録では、解約・休眠・単発の17社のうち、費用や条件で離れたとはっきり分かるのは3社だけでした。残りの多くは失速型です。
  2. 卒業型は止める必要がありません。「教える」商品は、うまくいくほど不要になります。問題は、卒業した経営者が次に買えるものが「月20万円の顧問を続ける」か「何も買わない」の二択しかないことです。
  3. 新メニューの主力は、自分でAIを使う経営者向けの保守・点検契約です（仮称「AI車検」）。作るのは顧客で、A社は「止めない・漏らさない・効果を測る」側に回ります。自分で運転する人が増えるほど、教習所の仕事は減りますが、車検と整備の仕事は増えます。Claude Code や Codex の普及は、この商品にとって追い風です。
  4. 失速型には、新商品ではなく既存契約の運用を直します。来週からできる5つの対策を第5章にまとめました。

1今のメニューは、全部「教える・作る」を売っている

添付資料の4メニューを「何を売っているか」「どう終わるか」で並べると、構造上の弱点が見えます。

メニュー 価格 売っているもの うまくいった時の終わり方

上の3つは、価値の中心が知識と技術の移転です。顧客が上達するほど、A社から買う理由が減ります。教習所が、免許を取った人に通い続けてもらえないのと同じ構造です。

クラブβの資料には「『学び』は続けにくい。でも『成果』は手放せない」とあります。この一文が、そのまま答えの方向を示しています。続けてもらうには、学びではなく、卒業した後も手放せない成果を売る必要があります。

2継続しない理由を、記録から分解する

A社の議事録と顧客マスタを集計した過去の分析（2026年7〜10月）から、離脱の理由を拾い直しました。

卒業型

自分でできるようになって離れる

ご質問の「ある程度学んだら自分でやりたい」はこちらです。記録にも、契約の節目で「月額の定額」を提示したところ、先方は「2〜3か月に1回のスポット」を希望し、折り合わずに離れた例があります。

これは支援が成功した結果です。止めるのではなく、卒業後に買える商品を用意します（第4章）。

失速型

自走の手前で止まって消える

宿題が進まない → 定例が情報共有会になる → 間隔が空く → いつの間にか消える。この流れが記録上は多数です。

こちらは支援の運用で防げます。新商品は要りません（第5章）。

記録から分かったこと

3／17社
社内記録解約・休眠・単発の17社のうち、費用や条件で止まったとはっきり記録があるのは3社だけ。残りは「宿題未消化 → 情報共有会化 → 間隔が空く → 消える」の同じ流れでした。
0／10社
社内記録休眠した継続先10社の最終回の議事録に、先方の成果の数字が1つもありませんでした。次回の日付も10社すべてで未記載です。成果が見えない支援は、続ける理由が説明できません。
5／10社
社内記録休眠側の半数は、毎回「新しいツールの紹介」が中心でした。もう半数は、PC・アカウント・社内のセキュリティ設定といった環境の問題で、価値が出る前に時間を使い切っていました（重複あり）。
4社すべて
社内記録解約した4社は、いずれも更新判断が「社内で検討します」で終わり、回答期限は記録されていませんでした。継続の形や料金を、契約の最終回で初めて出した例もあります。
4／9社
社内記録反対に、継続した側では9社中4社が「納品ではなく、自分で直せるようになる」をゴールにしていました。自走そのものは離脱の原因ではないということです。
1社が復活
社内記録休眠から戻った1社では、先方が自分で作ったものを持ってきて、A社がレビューする形に変わっていました。「まず自分で進める」と線を引かれても、関係は切れていません。新メニューの原型はこの関係です。
注記：「休眠」は議事録で60日以上接触がないことからの推定で、ChatworkやMessengerのやり取りは見ていません。ご質問の「304社・88人」と顧客マスタ（87社）は数え方が違うため、継続率や解約率は計算していません。

「Claude Code や Codex を自分で使っているから支援は要らない」という声は、時流と合っています。ただ、自分で使う人が増えると、別の困りごとも増えます。

3-3　まとめ：教習所から整備工場へ

これまでの需要

「AIの使い方を教えてほしい」
＝教習所。免許を取れば卒業する。

→

これから増える需要

「自分で使っているAIを、安全に止めずに回し、効果を示したい」
＝車検・整備・ロードサービス。運転者が増えるほど増える。

仮説この領域には、まだ担い手がいません。AI研修会社は「教える」で終わります。システム会社の保守は、社長が自分のPCで作ったAI環境までは見ません。セキュリティ会社は大企業向けで高額です。中小企業の経営者が自分で組んだAI環境を、定期的に見てくれる相手が空いています。市場規模のデータはないため、第6章の手順で確かめる前提です。

4新メニュー案：AI車検（仮称）

自分で Claude Code や Codex を使う経営者のための、AI環境の保守・点検契約です。

NEW MENU ｜ 主力案
AI車検 ── 自分で使う経営者の
「AI環境の保守・点検契約」

作るのは御社。止めない・漏らさない・効果を測るのはA社。

対象：顧問・Bootcamp・支援パックを卒業した経営者／Claude Code や Codex を自分で使っている経営者（クラブβ会員を含む）

① 月次点検読み取り専用の自己診断を顧客側で実行し、結果をA社が確認します。見るのは、権限の広さ、秘密情報の置き場所、バックアップの有無と場所、自動実行の一覧と失敗状況、AIの利用料、新モデルや料金改定の影響です。結果は赤・黄・緑の点検票と直し方で返します。
② 駆け込み復旧AIや自動化が止まった・詰まったときの窓口です。営業日48時間以内に一次回答します。社内記録で最も多い困りごと（「止まった」「設定で詰まった」）にそのまま応えます。
③ 本番投入前レビュー経営者や社員が作った自動化、スキル、社外に出す文面を、使い始める前にA社が確認します。ガイドラインが求める「人の確認工程」を外部に持つ形です。休眠から戻った1社の関係を商品にしたものです。
④ 四半期の成果報告時間・件数・商談数など、最初に決めた指標を、導入前と同じ物差しで測ります。幹部会議でそのまま使える1枚にまとめ、「続ける理由」を数字で残します。

なぜA社が提供できるのか

  • A社自身が、スキル165・エージェント31・自動実行15本・外部連携9系統（2026年8月時点）を日常業務で運用しています。権限の制限、失敗の検知と自動復旧、週次の点検を自社で回しているので、点検項目は机上の空論ではなく、運用の実地から作れます（「15.4人分」の実測と同じ環境です）。
  • CEOとCIOの2人体制に加え、AI専門家100名超のネットワークがあります。
  • 企業304社・経営者88人の卒業生が、最初の見込み客です。新規開拓をしなくても検証できます。

責任の範囲（契約で明記すること）

  • 点検は読み取り専用です。設定の変更は顧客自身が行うか、承認を得たうえで同席して行います。
  • 顧客のデータや秘密情報はA社に持ち出しません。共有するのは診断結果の要約だけです。
  • 点検は助言であり、事故が起きないことは保証しません。賠償の上限は月額料金の範囲とします。

5失速型への対策：既存の契約で来週からできる5つ

新商品を作る前に、今の契約の運用で防げる離脱があります。どれも費用はかかりません。

1. 契約満了の2〜3回前に「卒業後の選択肢」を出し、回答期限を決める

6確かめ方と撤退の基準

市場規模のデータがないため、作り込む前に小さく確かめます。

〜2週間：解約・休眠先と、卒業が近い経営者の5人に15分ずつ聞く。「自分で使い始めて困ったこと」と「月いくらなら払うか」の2点です。
〜1か月：A社自身の運用ルールから、点検票の第1版（30項目程度）と、読み取り専用の自己診断の手順を作る。
〜3か月：顧問・Bootcampの卒業生3人に、2か月の無償パイロットを行う（点検2回＋駆け込み対応）。
判定：3人中2人以上が有料での継続を希望すれば正式化します。正式化から6か月で契約が10社に届かなければ縮小し、クラブβの特典に格下げします。
計算例規模感の参考です。卒業生のうち30社が点検プラン（月5万円）、10社が整備プラン（月10万円）に入った場合、月250万円・年3,000万円です。加入数は仮定で、根拠のある見込みではありません。

A社が決める必要があること

  • 価格（月5万・10万円は案です）と、クラブβとのセット価格
  • CIOの稼働の上限（駆け込み対応の件数と回答時間に直結します）
  • 責任範囲の契約文言（読み取り専用・持ち出しなし・賠償上限）
  • 名称（「AI車検」は社内の仮称です）
